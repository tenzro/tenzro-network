# Contributing

This repository is a synced mirror of [`sdk/tenzro-ts-sdk/`](https://github.com/tenzro/tenzro-network/tree/main/sdk/tenzro-ts-sdk) in [tenzro-network](https://github.com/tenzro/tenzro-network). Code changes made here are overwritten by the next sync, so please do not open pull requests against this repo.

- Code changes (fixes, features): send them to `sdk/tenzro-ts-sdk/` in tenzro-network.
- Bug reports and questions about `npm install tenzro-sdk`: open an issue here using the templates.
- Security issues: do not open an issue. See [SECURITY.md](SECURITY.md).
