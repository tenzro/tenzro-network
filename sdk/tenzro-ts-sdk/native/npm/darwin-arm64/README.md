# @tenzro/device-key-darwin-arm64

The prebuilt native binary of [`@tenzro/device-key`](https://www.npmjs.com/package/@tenzro/device-key) for macOS on Apple silicon, Secure Enclave.

Do not install this package directly. `@tenzro/device-key` lists it as an optional dependency, and npm installs the one that matches the machine.
