# @tenzro/device-key-linux-x64-gnu

The prebuilt native binary of [`@tenzro/device-key`](https://www.npmjs.com/package/@tenzro/device-key) for Linux x64 (glibc), TPM 2.0.

Do not install this package directly. `@tenzro/device-key` lists it as an optional dependency, and npm installs the one that matches the machine.
