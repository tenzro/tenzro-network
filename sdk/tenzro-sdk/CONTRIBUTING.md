# Contributing

Issues and pull requests are welcome in this repository.

- **Bugs and questions**: open an issue — this is the home for `tenzro-sdk` on crates.io.
- **Code changes**: open a PR here; maintainers land it upstream in `sdk/tenzro-sdk/` (tenzro-network) as part of review, so a change here and the monorepo stay in sync. Run `cargo build` and `cargo test` first (Rust 1.85 or newer).
- **Security issues**: do not open an issue. See [SECURITY.md](SECURITY.md).
