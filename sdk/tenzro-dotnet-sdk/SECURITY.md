# Security policy

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue, pull
request or discussion for an unpatched vulnerability.

- Email **eng@tenzro.com**, or
- use GitHub private vulnerability reporting ("Report a vulnerability" under
  the Security tab) on this repository.

Include what you found, how to reproduce it, the version or commit, and the
impact you expect. Please do not test against other people's accounts or
nodes, and do not disclose the issue publicly until a fix is available.

## Scope

This repository: the `Tenzro.Sdk` .NET client library and its examples.
Issues in the node, CLI or other SDKs belong to those projects (see the
Tenzro organization).

## Supported versions

This SDK is pre-1.0. Security fixes go into the latest commit on `main`.
