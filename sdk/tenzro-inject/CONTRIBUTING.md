# Contributing

This repository is a synced mirror of the `sdk/tenzro-inject/` directory in
[tenzro-network](https://github.com/tenzro/tenzro-network). Code changes
belong upstream, in that directory; changes made here are overwritten by the
next sync.

- Bugs and feature requests: open an issue here, so `@tenzro/inject` has its own tracker.
- Security issues: do not open an issue; see [SECURITY.md](SECURITY.md).
- Local checks: `pnpm install --frozen-lockfile && pnpm test`.
