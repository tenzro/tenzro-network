# Contributing

Issues and pull requests are welcome in this repository.

- Bugs and feature requests: open an issue here — this is `@tenzro/inject`'s own tracker.
- Code changes: open a PR here; maintainers land it upstream in `sdk/tenzro-inject/` (tenzro-network) as part of review, so a change here and the monorepo stay in sync.
- Security issues: do not open an issue; see [SECURITY.md](SECURITY.md).
- Local checks: `pnpm install --frozen-lockfile && pnpm test`.
