Tenzro is installed

The hardware check ran during the install. To see its plain-language result again, open Terminal and run tenzro-check.

Next step: open a terminal and run: tenzro. The first time, it takes you through setup: use the network, provide compute, run a validator, or try a local chain. After that it opens the console. The Tenzro app in Applications opens that terminal for you.

On a Mac with a Secure Enclave the node keeps its identity keys there; they cannot be exported. A virtual machine without a Secure Enclave cannot run a validator node.
